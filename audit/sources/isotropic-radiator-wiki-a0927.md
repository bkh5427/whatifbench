An isotropic radiator is a theoretical point source of waves that radiates the same intensity of radiation in all directions.
an isotropic receiver (also called isotropic antenna) is a calibrated radio receiver with an antenna which approximates an isotropic reception pattern; that is, it has close to equal sensitivity to radio waves from any direction.
Since the antenna is isotropic, it has the same aperture in any direction.
